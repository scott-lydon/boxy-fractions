The problem and the shape of the answer

Worksheet fractions

Kid sees "1/2 = ?/4" on paper. Has to remember that the denominator doubled, so the numerator doubles. No intuition is built. Three days later they cannot do it.

Boxy Fractions

Kid drags a 1/2 piece onto a bar. Drags two 1/4 pieces onto a second bar. Sees the bars line up. The tutor names what they already see. Now they own it.

Per-component pros and cons

Fraction (value type)

Pros
  • Normalizes sign at construction
  • equivalentTo() is cross-product, no allocation
  • simplified() returns a new instance, immutability stays clean
Cons
  • Class instances cannot survive a JSON round-trip without a reviver
  • Number-typed numerator/denominator means integer-overflow is theoretically possible past 2^53

Bar (immutable container)

Pros
  • wouldOverflow() is pure, callable from any handler
  • Throws on illegal placement with a stack trace that points back to the bug
  • filledFraction() simplifies once at the end
Cons
  • Every placement allocates a new Bar (acceptable for 8-piece bars)
  • Order of pieces matters for rendering but not for math

Lesson state machine

Pros
  • Adding a stage is a new entry in the array
  • Click-advance and bar-fill-advance both supported
  • onEnterClearBars lets the script say "I cleared it" and have that be true
Cons
  • Branching is linear today, no DAG support
  • No persistence between reloads

Drag and drop (Framer + rect registry)

Pros
  • Pointer events, so iPad Safari and desktop mouse share code
  • Rect-based hit testing is one tiny module
  • Snap-back on miss keeps the tray full
Cons
  • Rect registry assumes no parent transform during drag
  • No keyboard alternative for accessibility (next iteration)

Trade-offs

No auto-deploy on push

Why I accept it: Public-repo Render setup needs no GitHub OAuth flow; the kid does not care that I trigger deploys with one button click.

When it would bite: If we iterate more than five times a day or want preview deploys per PR.

Bar manipulative, not polyomino game

Why I accept it: Grade 4 kid reads a bar in 30 seconds. Polyomino takes two minutes to teach.

When it would bite: If a hiring partner expects the more-novel manipulative to be the differentiator.

Manual test plan, not Vitest yet

Why I accept it: 8 happy-path cases cover the lesson. Five days is not enough to build the suite AND ship.

When it would bite: The second lesson lands and the cross-product of states explodes.
